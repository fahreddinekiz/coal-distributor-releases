# Kömür Dağıtım — Dağıtıcı Uygulaması

## Kurulum

1. Aşağıdaki **Releases** bölümünden en son `.apk` dosyasına dokunun
2. İndirme uyarısı çıkarsa **"Yine de indir"** deyin
3. İndirme bitince dosyaya dokunun
4. "Bilinmeyen kaynak" uyarısı çıkarsa **Ayarlar**'a gidip bu kaynağa izin verin, geri dönün
5. **Kur** deyin, Play Protect uyarısı çıkarsa **"Yine de kur"** deyin
6. Uygulama açılınca size verilen e-posta ve parola ile giriş yapın

## Güncelleme

Yeni sürüm çıktığında aynı adımları tekrarlayın. Uygulamayı silmenize gerek yok,
eski sürümün üzerine kurulur, verileriniz kaybolmaz.

**Önemli:** Teslimat yaparken internet bağlantınız yoksa kayıtlarınız telefonda
bekler. Gün sonunda internete bağlanıp uygulamayı açmayı unutmayın.
